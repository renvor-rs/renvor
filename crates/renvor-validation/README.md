# renvor-validation

Transport-independent validation boundary for the [Renvor](https://renvor.dev) framework.

A constraint is declared once, as a schema. Runtime validation interprets that schema; the OpenAPI
description embeds it. "Runtime validation and published schemas agree" is therefore an identity
rather than a property that tests have to chase.

## Stability

**This surface is explicitly unstable.** See the [`renvor`](https://crates.io/crates/renvor)
facade documentation.
