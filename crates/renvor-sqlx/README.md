# renvor-sqlx

The direct-SQLx adapter for the [Renvor](https://renvor.dev) framework.

Implements `renvor-database`'s transport-independent ports against PostgreSQL and MySQL.
Select exactly one database with the `db-postgres` or `db-mysql` feature; neither is default.

**Pre-release, unpublished, and explicitly unstable.**
