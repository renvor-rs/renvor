# renvor-cache

Cache capability for the [Renvor](https://github.com/renvor-rs/renvor) framework: a narrow key-value port with required TTLs and bounded keys and values, a deterministic in-memory substitute, and a Valkey (RESP) adapter behind the off-by-default `valkey` feature.

**Prerelease. Nothing here is published and no API is stable.**
