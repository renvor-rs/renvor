# renvor-mail

Mail capability for the [Renvor](https://github.com/renvor-rs/renvor) framework: a narrow mailer port whose messages are bounded and header-injection-free by construction, a recording substitute, an SMTP submission adapter behind the off-by-default `smtp` feature, and a bridge to `renvor_auth::MailPort` behind `auth`.

**Prerelease. Nothing here is published and no API is stable.**
