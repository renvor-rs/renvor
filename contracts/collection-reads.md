# Contract C-15 — Collection reads

**Status**: defined before implementation, per constitution principle V.
**Applies to**: `renvor-validation`'s collection contracts.

## This contract executes no query

**Nothing here opens a connection, builds a statement, or depends on a persistence crate.** What is
fixed is the **public shape** of a collection read: what a caller may ask for, which asks are
refused, and what a resumable position looks like. **Phase 006** connects that shape to storage.

Fixing it now is the point. A persistence phase that invented its own pagination would produce a
second public contract, and the first one would already be published.

## One principle, applied six times

**Declared allowlist, explicit refusal, bounded count.**

The alternative in every case is a silent choice — a clamp, a last-one-wins, an ignored parameter —
and constitution principle IV prohibits silent fallbacks.

**Everything is deny-by-default.** A field is filterable, sortable, includable, or selectable only
once it is named. A contract that started permissive would be one an author had to remember to
close.

## The cursor

| Question | Answer |
|---|---|
| **Opacity** | A cursor is an opaque string. Its internal structure is **not** a public contract, and a consumer that parses one relies on something Renvor does not promise |
| **Transport** | URL-safe and unpadded, so its length does not depend on where it is carried |
| **Versioning** | The encoded form carries an explicit version, **first**, checked **before** any interpretation |
| **Unrecognised version** | Refused **by name**, with its own reason. Never partially interpreted |
| **Malformed, truncated, foreign** | Refused as an invalid parameter |
| **Panics** | **Decoding MUST NOT panic on any input.** Asserted by property testing over generated bytes, generated alphabet text, valid cursors with a foreign version byte, and valid cursors with one character corrupted |
| **Size** | Bounded, and the bound is checked **before** decoding — so an over-long value is refused rather than decoded and then measured |

The version check exists for the reason [`http-routing.md`](http-routing.md) already states about
the route-dump payload: *"parsing an unknown version on a best-effort basis"* is how output silently
loses a field. A page is the same hazard with worse consequences — a best-effort decode of a foreign
cursor yields a position that is syntactically fine and semantically meaningless, so the caller
receives a page from nowhere and cannot tell.

## Ordering is total

A declared sort is always completed with a **tiebreaker**, so no two records compare equal.

> With a non-total ordering, two tied rows can be returned in different relative orders across
> pages, so a record is **skipped or repeated** — and nothing in the response says so. This is a
> correctness property, not a nicety, and it is **not optional**: an optional correctness property
> is one that is absent whenever nobody thought about it.

The tiebreaker is present even when the caller supplied no sort at all.

## Page size

A declared **default**, **minimum**, and **maximum**. A request outside them is **refused**, naming
the bound — **never clamped**.

> Clamping hands a caller a different result from the one they asked for and says nothing about
> having done so. [`http-runtime.md`](http-runtime.md) already establishes that Renvor refuses
> rather than clamps, and asserts bounds *"at the exact boundary and at boundary + 1"*.

A page size that is not a number is a **type mismatch**, not a range failure: different mistakes
call for different corrections.

## Filters, sorts, includes, fields

| Concern | Rule |
|---|---|
| **Filter keys** | Allowlist per operation. An unknown key is refused |
| **Filter operators** | A **closed** set, declared per field: `eq`, `ne`, `lt`, `le`, `gt`, `ge`. An open-ended vocabulary is how a filter parameter becomes a query language, and a query language on a public endpoint is an unbounded amount of work a caller gets to choose |
| **Sort keys** | Allowlist per operation, with direction from a closed set |
| **Duplicate query keys** | A **reported failure**. Not last-one-wins, not first-one-wins — a silent winner depends on ordering nobody wrote down |
| **Unknown query parameters** | Refused. An ignored parameter is how a caller's typo becomes a silently different result |
| **Sparse fields** | Allowlist of selectable fields; count bounded |
| **Includes** | Allowlist of includable relations; **count and depth bounded**. Unbounded includes are the N+1 amplification [`PLAN.md`](../PLAN.md) §11.2 names for GraphQL, and the same hazard exists here |
| **Every list-shaped input** | Carries a maximum count, asserted at the boundary and boundary + 1 |

## A refused key is not echoed

A key that **matched** the allowlist is the contract's word, and naming it in an issue is safe. A key
that **failed** it is caller-chosen, so the issue names the parameter family — `sort`, `include`,
`fields`, `filter` — and not the key's text.

## Filter values are never interpolated

An accepted filter carries its value **uninterpreted**. Phase 006 binds it as a parameter.
Constitution principle VI requires parameter binding, and a value that reached a statement by string
concatenation would be an injection whichever phase performed it.
